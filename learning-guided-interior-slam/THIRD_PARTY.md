# Third-Party Software and Data

This folder contains original experiment scripts and result summaries for the portfolio project.

It does **not** vendor:

- MASt3R-SLAM source code or model weights;
- TUM RGB-D images, depth maps, calibration files, or trajectories;
- PyTorch, Open3D, OpenCV, SciPy, Trimesh, or other dependencies.

The validated MASt3R-SLAM commit is recorded in `configs/mast3r_slam_commit.txt`. Install and use third-party software according to its upstream license and documentation.

TUM RGB-D data must be obtained directly from the benchmark and used according to its terms.

No license is granted here for third-party code, models, or datasets.
