# Result summaries

The committed JSON files summarize the completed 12-view ETH3D Courtyard experiment.

- `milestone1_12views/eth3d_camera_pose_evaluation.json`: camera-pose alignment metrics for VGGT feed-forward, VGGT plus bundle adjustment, and COLMAP.
- `milestone2_final/milestone2_summary.json`: dense hybrid reconstruction comparison and the selected adaptive fusion variant.

These are diagnostic evaluations against a sampled ETH3D laser scan using a common visible-region crop. They are not official ETH3D leaderboard scores.
